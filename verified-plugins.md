# Verified Plug-ins
Here's a list of plugins different people have verified working, using either the script in this repo, or just by using **wine-staging-9.21**. The script in this repo by default applies the dxvk patch.

Contributions to this list are more than welcome!

Note that some additional plugins are mentioned in [official yabridge page](https://github.com/robbert-vdh/yabridge), including advanced setup and troubleshooting steps.
